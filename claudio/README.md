# Exercício

- Criar um agente de ia que precisa ter ferramentas para:
  - ler arquivos
  - ler diretórios
  - escrever arquivos
  - e executar código (os subprocess executando o que ele acabou de escrever e ver se deu erro ou não)
  - prompts para testes:
    - write a file src/hello.py with one "Hello world" message.
    - execute the file src/hello.py and show the result code and the output.
    - read the file src/hello.py and show the content.
    - fix the file src/hello.py to print "Hello, World!" instead of "Hello world" and execute it again.
